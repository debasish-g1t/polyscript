    Extender

    The extender grows a polymer from one or more monomer structures by applying the reaction recipe registered for its polymer family. The registry (polyscript.extender.map.rxn_map) is pure data; each entry selects a driver and supplies reaction SMARTS.

    Mechanism classes

    type driver growth event
    addition ChainGrowthReaction wildcard propagation; initiation and termination provide the end groups
    step_growth StepGrowthReaction condensation of one chain functional group with one monomer functional group
    ring_opening RingOpeningReaction open the cyclic monomer (or a balanced anhydride + epoxide + water unit), then propagate the opened unit with a ROP-specific coupling
    romp RingOpeningMetathesisReaction programmatic ring cut and insertion of one cycloalkene per propagation
    ring_open StepGrowthReaction legacy open-then-condense form with a generic coupling

    reaction_config(key) is the single entry point for building driver kwargs. It injects the map key as ring_open_smarts for ring_open/ring_opening and as ring_bond_smarts for romp.

    Ring-opening polymerisation

    Ring-opening polymerisation (ROP), ring-opening copolymerisation (ROCOP), and ring-opening metathesis polymerisation (ROMP) are insertion/chain-growth processes. A cyclic monomer is not an AB monomer even though its opened form can look like one.

    The registry uses ring_opening to open the ring into its real open form and then propagate the opened unit:

    • ROP. Water is the initiator: opening the first lactone/lactam adds water across the scissile bond, so the first residue is a hydroxyacid/aminoacid and has one more oxygen than the cyclic monomer. Later residues add only the monomer's own atoms. lactone_rop/lactam_rop avoid the generic amide/ester guards that rejected the R11 and R12 opened end groups.
    • ROCOP. The balanced ROCOP_OPENING_SMARTS consumes one water molecule: the anhydride ring O becomes the ester O, the water O becomes the acid O-H, and the epoxide O becomes the terminal alcohol. One cycle consumes one anhydride + one epoxide pair.

    For PES, succinic anhydride (3 O) + ethylene oxide (1 O) + water (1 O) gives the first opened residue with 5 O. The extra oxygen is the water initiator.

    This is a stoichiometric/topological model: it reproduces the terminated chain directly and does not track an active-end dummy or a separate termination event. The insertion/active-end variant was prototyped and removed from the active code path because the topological model produces the same final chains for the known polymer examples while remaining faster and simpler. ROMP uses a programmatic ring cut because a variable-size ring cannot be opened by one generic two-reactant SMARTS in RDKit.

    ROMP

    ROMP cuts the metathesis C=C double bond named by the map key and joins repeat units through new double bonds at the junctions. RingOpeningMetathesisReaction performs the cut programmatically: initiation opens one ring, caps one side with the initiator fragment through a double bond and leaves a double-bonded dummy at the growing end; propagation opens the next ring, forms a double bond to the chain and moves the dummy; termination replaces the dummy with the terminator fragment through a double bond. This is necessary because the ring path is variable-length and cannot be expressed as one generic two-reactant SMARTS.

    def chain_extend(self, monomers: list, chains: list | None = None):
    """Extend every chain by one propagation step.

    Args:
        monomers: Monomer pool available for the propagation reaction.
        chains: Chains to extend.  Defaults to the result of the most
            recent :meth:`chain_init`/:meth:`chain_extend` call.

    Returns:
        list[rdkit.Chem.Mol]: Extended chains ending in a wildcard,
        capped to ``max_products``.  Once the cap is reached, remaining
        parent chains and reaction assignments are not evaluated.
    """
    if chains is None:
        chains = self._chains
    if not chains:
        return []

    pool = self._prepare_monomers(monomers)
    extended = []
    for chain in chains:
        remaining = (
            None
            if self.max_products is None
            else self.max_products - len(extended)
        )
        if remaining is not None and remaining <= 0:
            break
        extended.extend(
            self._run(self.prop_rxn, pool, chain=chain, limit=remaining)
        )

    self._chains = self._trim(extended)
    return self._chains

    def extend(
    self,
    monomers: list,
    length: int,
    return_intermediate: bool | None = None,
):
    """Build terminated chains containing ``length`` propagation steps.

    Args:
        monomers: Monomer pool.  Each item may be a SMILES string or an
            ``rdkit.Chem.Mol``.  Every propagation step may pick any
            member of the pool, including the same one repeatedly, so a
            multi-monomer pool enumerates all sequences of that length.
        length: Number of propagation steps performed after initiation.
            ``0`` returns the terminated initiation product.
        return_intermediate: Per-call override.  ``None`` (default)
            uses the instance setting
            :attr:`~ChainGrowthReaction.return_intermediate`.  ``True`` also
            returns the growing product after initiation and after every
            propagation step; ``False`` returns only the final molecules.
            Intermediates retain the wildcard at the growing end; the
            ``final`` entry is the terminated molecule.  The trace is not
            built when tracing is disabled.

    Returns:
        list[str]: Canonical SMILES of the terminated chains when tracing
        is disabled.  At most ``max_products`` chains are retained after
        initiation and after every propagation step.

        dict: When tracing is enabled::

            {
                "intermediates": [
                    ["...*"],   # after initiation (n=0)
                    ["...*"],   # after propagation step 1
                    ...
                ],
                "final": ["..."],  # after termination
            }
    """
    if not isinstance(length, int) or length < 0:
        raise ValueError("length must be a non-negative integer")
    if return_intermediate is not None and not isinstance(
        return_intermediate, bool
    ):
        raise TypeError("return_intermediate must be a bool or None")

    trace = (
        self.return_intermediate
        if return_intermediate is None
        else return_intermediate
    )
    intermediates: list = []

    chains = self.chain_init(monomers)
    if trace:
        intermediates.append([Chem.MolToSmiles(mol) for mol in chains])

    for _ in range(length):
        if chains:
            chains = self.chain_extend(monomers, chains)
        else:
            # Keep one trace entry per requested step even if growth
            # stopped early.
            if trace:
                intermediates.append([])
            continue
        if trace:
            intermediates.append([Chem.MolToSmiles(mol) for mol in chains])

    terminated = self.chain_term(monomers, chains)
    final = [Chem.MolToSmiles(mol) for mol in terminated]

    if trace:
        return {"intermediates": intermediates, "final": final}
    return final

    def couple(self, chain, monomers):
    """Run every coupling reaction on *chain* and a monomer/reagent pool.

    Both reactant orders and all chain/template assignments are tried.
    The returned molecules are single connected products with no
    wildcards; the monomers' unreacted functional groups are carried over.
    """
    pool = prepare_monomers(monomers)
    products = []
    for rxn in self.coupling_rxns:
        products.extend(self._run_coupling(rxn, chain, pool))
    return self._dedupe(products)

    def extend(
    self,
    monomers,
    length: int,
    return_intermediate: bool | None = None,
):
    """Build chains containing ``length`` monomer residues.

    Args:
        monomers: Monomer pool.  Each item may be a SMILES string or an
            ``rdkit.Chem.Mol``.  Both components of an ``AA`` + ``BB``
            pair are supplied in the same pool; the coupling reactions
            determine which combinations can react.
        length: Number of monomer residues in the final chain.  ``1``
            returns the supplied monomers, ``0`` returns an empty chain.
        return_intermediate: Per-call override.  When enabled, returns the
            chain after initialization and after every coupling step.

    Returns:
        list[str]: Canonical SMILES of the final chains.

        dict: When tracing is enabled::

            {
                "intermediates": [
                    ["..."],   # one monomer residue (n=1)
                    ["..."],   # after one coupling (n=2)
                    ...
                ],
                "final": ["..."],
            }
    """
    if not isinstance(length, int) or length < 0:
        raise ValueError("length must be a non-negative integer")
    if return_intermediate is not None and not isinstance(
        return_intermediate, bool
    ):
        raise TypeError("return_intermediate must be a bool or None")

    trace = (
        self.return_intermediate
        if return_intermediate is None
        else return_intermediate
    )
    intermediates: list = []

    if length == 0:
        self._chains = []
        if trace:
            return {"intermediates": intermediates, "final": []}
        return []

    pool = self._prepare_pool(monomers)
    if not pool:
        raise ValueError("No monomers provided for step-growth extension")

    chains = self._dedupe(pool)
    if trace:
        intermediates.append([Chem.MolToSmiles(mol) for mol in chains])

    for _ in range(length - 1):
        if chains:
            chains = self._couple(chains, pool)
        if trace:
            intermediates.append([Chem.MolToSmiles(mol) for mol in chains])
        if not chains:
            continue

    self._chains = self._trim(chains)
    final = [Chem.MolToSmiles(mol) for mol in self._chains]

    if trace:
        return {"intermediates": intermediates, "final": final}
    return final

    for chain in chains:
        if not self._has_wildcard(chain):
            raise ValueError(
                "The chain passed to ROMP propagation has no growing end"
            )
        for mol in pool:
            for match in self._matches(mol):
                try:
                    extended.append(
                        self._insert(
                            Chem.Mol(chain),
                            Chem.Mol(mol),
                            match,
                        )
                    )
                except Exception:
                    continue
                if (
                    self.max_products is not None
                    and len(extended) >= self.max_products
                ):
                    self._chains = self._trim(extended)
                    return self._chains
    self._chains = self._trim(extended)
    return self._chains

    def chain_term(self, monomers, chains=None):

    def extend(
    self,
    monomers,
    length: int,
    return_intermediate: bool | None = None,
):
    """Build ROMP chains with ``length`` propagation steps.

    ``length == 0`` returns the terminated initiation product.  Each
    propagation step inserts one cycloalkene ring.  The returned products
    contain no dummy atoms.
    """
    if not isinstance(length, int) or length < 0:
        raise ValueError("length must be a non-negative integer")
    if return_intermediate is not None and not isinstance(
        return_intermediate, bool
    ):
        raise TypeError("return_intermediate must be a bool or None")

    trace = (
        self.return_intermediate
        if return_intermediate is None
        else return_intermediate
    )
    intermediates: list = []

    chains = self.chain_init(monomers)
    if trace:
        intermediates.append([Chem.MolToSmiles(mol) for mol in chains])

    for _ in range(length):
        if chains:
            chains = self.chain_extend(monomers, chains)
        if trace:
            intermediates.append([Chem.MolToSmiles(mol) for mol in chains])

    terminated = self.chain_term(monomers, chains)
    final = [Chem.MolToSmiles(mol) for mol in terminated]

    if trace:
        return {"intermediates": intermediates, "final": final}
    return final

    map

    Reaction SMARTS registry and mechanism recipes for chain extension.

    rxn_map is keyed by the reaction SMARTS recorded for a polymer family. Every value is pure data; the reaction objects are compiled lazily by the driver selected for the entry's type. Each entry also carries a mechanism code (A1–R5) that ties it to benchmarks/mechanism_table.tex and the persistent example manifest benchmarks/mechanism_examples.json. The mechanisms are:

    addition Chain-growth from init_smarts / prop_smarts / term_smarts. The growing end is a wildcard; initiation and termination supply the end groups. The configured polyolefin entries use hydrogen caps: the termination product removes the wildcard, so no extra methyl carbon is invented. This is the chain-transfer/β-hydride-elimination end group of coordination polymerisation and the H-ended product of radical disproportionation, rather than a methyl-capped chain.

    step_growth Condensation by stepwise coupling of real monomer functional groups. coupling_smarts consumes one functional group from the chain and one from a monomer; the monomer's other groups are carried over unchanged. This is not wildcard propagation and does not synthesize end groups. It covers ester, amide, urethane, imide, oxazolidinone, carbonate, NAS aryl ether, and oxidative phenol coupling.

    ring_open / ring_opening Ring-opening polymerisation (ROP) and copolymerisation (ROCOP) in the open-then-condense form. The map key opens the cyclic monomer into its real open form; the opened monomer is then inserted with a ROP-specific coupling. The final chain carries real terminal groups.

    This is a **stoichiometric/topological** model, not an active-end insertion
simulation.  It does not track a growing dummy or a separate termination
event; it reproduces the terminated chain directly.  The stoichiometry
includes the initiator explicitly:

* a water-initiated lactone/lactam opens to a hydroxyacid/aminoacid, so
  the first residue has one more oxygen than the cyclic monomer;
* the ROCOP opening is the balanced anhydride + epoxide + water reaction,
  so the first residue has one more oxygen than the two monomers.

Later residues add only the monomer's own atoms.  The extra first-residue
oxygen is the water initiator, not an invented atom.  ``ring_open`` is the
legacy spelling of the same driver with a generic coupling; the registry
uses ``ring_opening`` with the ROP-specific couplings.

    romp Ring-opening metathesis polymerisation. The reactant side of the map key names the ring alkene and an allylic atom so a variable-size ring can be found. The driver cuts the C=C double bond (the metathesis event), caps one cut end with the initiator, leaves the other as a double-bonded growing end, and joins each new repeat unit through a new double bond. Termination caps the growing end with the configured terminator. It does not keep the ring alkene and cleave the allylic single bond.

    Why ring-opening propagation has its own couplings

    A cyclic monomer is not an AB step-growth monomer. Opening a lactone gives a hydroxyacid, opening a lactam an aminoacid, and opening an anhydride + epoxide pair gives a hydroxyacid with an ester linkage. Those open forms can look like step-growth monomers, but the propagation event is an insertion into an intact ring. The generic ester/amide guards used to reject two real opened ends:

    • a broad amide guard rejected an amine attached to an amidine/thioimidate carbon. A thioimidate lactam (R11) opens to exactly that amine.
    • a broad ester guard rejected an acyloxy O-H whose carbonyl is attached to nitrogen. A cyclic carbamate/carbonic anhydride such as the oxazine-2,6-dione in R12 opens to that carbamic-acid end.

    The ROP-specific couplings in :data:RING_OPENING_PROPAGATIONS keep the chemically correct guard and add only the missing carbamic-acid case:

    • lactone_rop excludes carboxylic acid, ester, carbonate, sulfonic, boronic, phosphoric, oxime, and peroxide O-H from the nucleophile slot, but allows an alcohol and the O-H of a carbamic acid (N-C(=O)-O-H).
    • lactam_rop excludes amide/imide/thioamide, sulfonamide, and phosphoramide nitrogen, but allows an amine attached to an amidine/thioimidate carbon (C=N).

    A literal direct attack on the intact ring is the chemically cleanest form, but a single reaction SMARTS cannot describe the variable-length ring path between the scissile atoms. When such a template is used with two reactants, RDKit partitions the unmapped path across the dot-separated product components and returns the opened monomer as two fragments. The open-then-condense form avoids that RDKit limitation and still produces the same terminated chain as an active-end insertion model for the known polymer examples. Small rings whose atoms can all be mapped are the exception: the three-membered epoxide in epoxide_rop is attacked directly and remains a step_growth entry.

    ROCOP oxygen accounting

    The anhydride + epoxide dataset key is a repeat-unit topology, not a balanced elementary step. The registry uses :data:ROCOP_OPENING_SMARTS, a balanced three-reactant opening (anhydride + epoxide + water):

    • the anhydride ring O becomes the ester O;
    • the water O becomes the remaining acid O-H;
    • the epoxide O becomes the terminal alcohol.

    opening_reagents supplies the water to the opening step only; it is consumed and not added to the propagation pool. For PES:

    ::

    succinic anhydride (3 O) + ethylene oxide (1 O) + water (1 O)
    -> HOOC-CH2-CH2-COO-CH2-CH2-OH (5 O)

    The extra oxygen is the initiator. One cycle consumes one anhydride + one epoxide pair, which matches the alternating ROCOP repeat unit.

    Chemoselectivity guards

    The step-growth couplings use explicit functional-group guards instead of the old negative lookaheads:

    • an alcohol/phenol/thiol nucleophile must not be an acyloxy O-H (carboxylic acid, ester, carbonate), a sulfonic/boronic/phosphoric acid, an oxime or hydroxylamine O-H, a peroxide, or an enol ether;
    • a free amine must not be an amide/imide/thioamide (N-C(=O/S)), sulfonamide, or phosphoramide, but amidine/thioimidate N-C(=N) is allowed;
    • NAS aryl ether coupling requires the aryl halide to be para-activated by a ketone, sulfone, or nitrile; unactivated aryl halides do not match. The activating group may be on the halide ring or on a directly attached phenyl spacer (PEEK/PES/PAEN analogs);
    • imide formation requires a cyclic (five- or six-membered) anhydride, so an acyclic anhydride cannot be scrambled into an acyclic imide;
    • ROCOP opening accepts five- and six-membered anhydrides whose ring atoms flanking the carbonyls may be carbon, nitrogen, oxygen, or sulfur, so diglycolic and other heteroatom anhydrides open as well;
    • oxidative phenol coupling requires both ortho positions of the coupling ring to be blocked, so unsubstituted phenol is not accepted as a linear PPO monomer;
    • polyester coupling supports both acid/acyl-halide esterification and methyl-ester transesterification (the DMT route). The transesterification template is methyl-specific so it cannot cleave backbone esters;
    • isocyanate + epoxide and epoxide ROP attack the less hindered epoxide carbon; regioisomeric mixtures are only produced where the two carbons are equivalent by substitution;
    • carbonate linkages use phosgene as the carbonyl source (2 R-OH + Cl2C=O -> R-O-C(=O)-O-R + 2 HCl), not direct CO insertion, which would remove H2 without an oxidant.

    Mechanistic scope

    The step-growth recipes reproduce the net repeat-unit chemistry. They do not track transient intermediates whose lifetime is shorter than one coupling cycle:

    • a carbonate coupling is written as the balanced two-alcohol + phosgene net reaction; a real process can also stop at a chloroformate or half-carbonate ester;
    • imide formation is written as the net cyclodehydration; the open poly(amic acid) is not represented as a separate residue;
    • the R15/R16 polyolefin keys name two alkene comonomers. The template inserts one unit of each in the same propagation step, so the model gives a strictly alternating ABAB copolymer that matches the dataset's comonomer pair. It is not a conjugated-diene 1,4-addition (which would retain one backbone C=C);
    • epoxide ROP is represented by the water-initiated coupling of the intact epoxide. The product stoichiometry is correct, but the driver does not simulate a metal alkoxide active end.

    Oxidative phenol coupling

    Poly(phenylene oxide) synthesis is a step-growth C-O coupling, not a ring-opening reaction. It is configured with phenol_oxidative in :data:STEP_GROWTH_COUPLINGS; the phenolic O-H of one ring couples to the para C-H of another ring, and the second ring's O-H is carried over as the real terminal group. Both ortho positions of the coupling ring must be blocked, so unsubstituted phenol is not accepted as a linear PPO monomer.

    Terminal-group and atom provenance

    • addition entries: end groups come from init_smarts/term_smarts. Wildcards in the repeat-unit key are main-chain cut points, not end groups. The configured polyolefin termination removes the wildcard, giving a hydrogen end rather than an extra methyl carbon.
    • step_growth entries: a coupling consumes one functional group from the chain and one from a monomer. RDKit carries the rest of the monomer through unchanged, so the polymer keeps the monomer's exact unreacted end groups (-COOH, -COCl, -OH, -SH, -NH2, -N=C=O, -N=C=S, Ar-F/Ar-Cl, epoxide, anhydride, phenol, ...). No end group is synthesized from a wildcard. The carbonate recipe consumes an explicit phosgene reagent; its carbonyl carbon and oxygen are reagent atoms, not invented atoms.
    • ring_open/ring_opening entries: the opened monomer is the source of end groups. Ring opening is the only inference; the balanced ROCOP opening additionally consumes an explicit water initiator. The first residue's extra oxygen is that initiator. No heavy atom is synthesized from a wildcard.
    • romp entries: the initiator and terminator fragments are explicit recipe parameters. Ring opening cuts the C=C bond and does not synthesize a heavy atom.
    • Entries mapped to None would be unconfigured. The registry currently has no None entries; a mechanism that needs new chemistry should be added here with an explicit recipe rather than guessed at run time.

    Use :func:reaction_config to build the driver kwargs. For ring_open and ring_opening entries it injects the map key as ring_open_smarts; for romp entries it injects the map key as ring_bond_smarts.

    def reaction_config(key):
    """Return driver kwargs for a configured ``rxn_map`` entry.

    ``ring_open``/``ring_opening`` entries use the map key itself as the
    ring-opening SMARTS, and ``romp`` entries use it as the ring-bond SMARTS,
    so the key is not duplicated in the configuration dictionary.
    """
    config = rxn_map[key]
    if config is None:
        raise ValueError(f"No extender recipe configured for {key!r}")
    params = dict(config["params"])
    if params.pop("ring_open", False):
        params["ring_open_smarts"] = key
    if config.get("type") == "ring_opening":
        params.setdefault("ring_open_smarts", key)
    if config.get("type") == "romp":
        params.setdefault("ring_bond_smarts", key)
    return params
