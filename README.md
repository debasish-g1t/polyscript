# PolyScript

Polymer chemistry sequence generation, classification, validation, and depolymerization.

## Installation

Install directly from PyPI:

```bash
pip install polyscript-pypi
```

To install from source for development:

```bash
pip install -e .
```

## Documentation

To build the documentation locally, install the docs dependencies and run mkdocs:
```bash
pip install .[docs]
mkdocs build
```

## Testing

```bash
pip install .[test]
pytest tests/
```
